Run IMPORT_MATCHED_CARDSDLL.cmd to import a legally obtained copy. It is stored
under required/ by build number. RUN_LOCAL_FUT13.cmd waits for the running game
to reveal its Blaze runtime build at the main menu, then pairs the matching DLL
before Ultimate Team is allowed to load. No fifa13.exe hash allow-list is used.
